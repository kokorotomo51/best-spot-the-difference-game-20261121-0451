# Spot the Oddity — A Midnight Museum Mystery

Entered in [best-spot-the-difference-game-20261121-0451](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451).

A complete spot-the-difference game that runs offline in a desktop browser from
static files. You are the night curator of a peculiar little museum. In each of
three hand-drawn rooms — the Midnight Museum hall, the Alchemist's Study, and
the Moonlit Garden — two near-identical scenes hang side by side, and 7 details
differ between them. Find them all: click a difference directly, or move the
glowing crosshair with the arrow keys and press Enter. Hints are limited, and a
wrong mark costs points and time.

Every scene, sound, and name is original and generated by the game's own code:
the artwork is procedural canvas drawing (no image files), the sounds are
WebAudio tones generated on the fly, and nothing is fetched over the network.

## How to play

- **Mouse:** click a difference on either panel.
- **Keyboard:** arrow keys move the crosshair, **Enter**/**Space** marks it,
  **H** uses a hint, **M** toggles sound.
- **Goal:** 7 differences per room, 3 rooms. Each find scores 100 points;
  clearing a room adds a time bonus plus 50 points per unused hint.
- **Screenshots:** the `?shot=` states render the title screen, a mid-game
  moment with 3 of 7 found, and the win screen, deterministically for `seed=1`.

## Run it

```sh
node serve.ts            # serves game/ at http://localhost:8080
```

Open http://localhost:8080 in a desktop browser. No build step, no network.

## Layout

- `main.ts` — hand-in program: copies `game/` and `screenshots/` to the output
  directory and writes `dossier.json` with the kit's `buildDossier`.
- `serve.ts` — tiny static server for local play-testing.
- `game/index.html` — page shell and HUD.
- `game/style.css` — page styling.
- `game/src/main.js` — game controller: state machine, input, rendering,
  `?shot=` states.
- `game/src/scenes.js` — the three-round scene list.
- `game/src/scene-museum.js`, `scene-study.js`, `scene-garden.js` — the three
  procedural scenes and their 7 differences each.
- `game/src/draw.js` — shared canvas helpers (frames, markers, moon, flame).
- `game/src/prng.js` — seeded random for deterministic layouts.
- `game/src/audio.js` — WebAudio sound effects.
- `shots.json` — the three screenshot states.
- `screenshots/` — real renders of the game running in a browser.
